# Timetable — Teacher guide

The *Timetable* block shows the calendar events of today, of a day of this week or of the upcoming days:
activity dates such as assignment due dates, course events, group events and each user's own events. In a
course it shows the events of the course; on the Dashboard, the events of all the user's courses.

## Adding the block

1. Turn **Edit mode** on in your course.
2. Open the block drawer and select **Add a block ▸ Timetable**.

The block works without any settings: it shows today's events and offers all three views.

## Settings

Open the block's actions menu and select **Configure Timetable block**.

| Setting | What it does |
| --- | --- |
| **Default view** | The view the block shows first: *Today*, *This week* or *Upcoming*. |
| **Views to switch between** | The views users can switch to with the buttons at the top of the block. The default view is always offered. With only one view, there are no buttons. |
| **Events per page** | How many events the block shows at a time, from 1 to 50 (default 5). When there are more, users page through them with *Previous events* and *Next events*, up to 200 events. |
| **Orientation** | *Vertical* lists the events below each other. *Horizontal* shows them as cards side by side, which suits wide regions. |

You can add several Timetable blocks with different settings, for example *Today* in one block and
*Upcoming* in another.

## The views

- **Today** — the events of today.
- **This week** — a button for each day of the week, today first selected. The week starts on the first day of
  the week of each user's calendar preferences.
- **Upcoming** — the events from today on, for as many days as each user's *Upcoming events look-ahead*
  calendar preference (the site's default otherwise).

Events that have ended are dimmed. Selecting an event opens its details as in the calendar; if you can manage the
event, you can edit or delete it there.

## What learners see

In a course, the block shows the same events as the course calendar, except site and category events, which
are left on the Dashboard:

- course events and the dates of the activities they can see,
- events of the groups they belong to (users who can access all groups see every group's events),
- their own user events.

Events of hidden activities are not shown, also not to teachers, as in the calendar. Every user only sees the
events they are allowed to see.

Visitors who are not logged in, for example on the site home, see the default view without the buttons.

The footer links to the calendar and, for users who can manage calendar entries, to a new event.
